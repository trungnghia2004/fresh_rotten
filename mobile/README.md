# Fresh/Rotten Mobile (React Native)

This is a standalone React Native (Expo) app to upload images/videos or capture from camera and show prediction results.

## Setup

```
cd mobile
npm install
npm run start
```

## Important
- For real phones, set API Base URL to your PC LAN IP (e.g. http://192.168.1.10:8000).
- The backend must be running (see root app.py).
